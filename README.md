# 👾 Zigbee2MQTT ZBOSS App for Home Assistant (HAOS)

Repositório oficial do App **Zigbee2MQTT ZBOSS** para Home Assistant OS, desenvolvido para o Coordenador Zigbee 3.0 em placas **ESP32-C6**.

## 📌 URL do Repositório (Copie e cole no HA)

```text
https://github.com/wesioplayconstructor/zboss-zigbee2mqtt-app
```

## 🛠️ Instalação no Home Assistant

1. No Home Assistant, vá em **Configurações → Apps → App Store** (ou **Add-on Store**).
2. Clique nos **3 Pontinhos** (menu superior direito) ➔ **Repositórios**.
3. Adicione `https://github.com/wesioplayconstructor/zboss-zigbee2mqtt-app`.
4. Procure por **Zigbee2MQTT ZBOSS (ESP32-C6)**, clique em **Instalar** e depois em **Iniciar**.
