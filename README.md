# 👾 Zigbee2MQTT ZBOSS App for Home Assistant (HAOS)

Repositório oficial do App **Zigbee2MQTT ZBOSS** para Home Assistant OS (HAOS 2026.5+), desenvolvido para o Coordenador Zigbee 3.0 em placas **ESP32-C6** da Espressif.

## 📌 URL do Repositório (Copie e cole no HA)

```
https://github.com/wesioplayconstructor/zboss-zigbee2mqtt-app
```

## 🛠️ Instalação no Home Assistant

1. Vá em **Configurações → Apps → App Store** (ou **Add-on Store**).
2. Clique nos **3 Pontinhos (Menu)** ➔ **Repositórios**.
3. Cole `https://github.com/wesioplayconstructor/zboss-zigbee2mqtt-app` e clique em **Adicionar**.
4. Procure por **Zigbee2MQTT ZBOSS (ESP32-C6)**, clique em **Instalar** e depois em **Iniciar**.
